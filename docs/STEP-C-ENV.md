# Шаг C — Ключи на компьютер + проверка мозга

Сейчас связываем твои аккаунты с кодом **только у себя на машине**.  
Ключи в чат / GitHub **не отправляй**.

---

## Важно: куда именно класть

Нужен файл: **`apps/api/.env`**  
(не `.env.example` в корне — example это шаблон без секретов).

Куратор уже перенёс твои значения из example → `apps/api/.env`.  
Дальше правь **только** `apps/api/.env`.

---

## Как взять ключ Qdrant (то, чего не хватает)

1. Открой [cloud.qdrant.io](https://cloud.qdrant.io).
2. Кликни **на свой кластер** (не на общий Dashboard только — именно cluster).
3. Секция / вкладка **API Keys**.
4. **Create** → имя `smm-os-dev` → Create.
5. Ключ покажут **один раз** → Copy.
6. Открой `apps/api/.env`, найди строку:

```bash
QDRANT_API_KEY=
```

7. Вставь сразу после `=` (без пробелов и кавычек):

```bash
QDRANT_API_KEY=вставь_сюда_ключ
```

8. Сохрани файл.

Если окно с ключом уже закрыла — **Create** ещё один ключ (старый можно удалить в списке).

### Не путать URL и ключ

У тебя URL уже есть и выглядит правильно (`https://….cloud.qdrant.io`).  
Ключ — это **другая** длинная строка, **без** `https://`.
